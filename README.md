# F1 Analytics Lab

## Objective

Analyze how driver and constructor performance evolves over time and identify resilient teams and unpredictable circuits using historical Formula 1 race data.

## Tools

* SQL / BigQuery
* Python (pandas)
* Tableau Public

## Key analyses

* Rolling driver win-rate trends
* Constructor drawdown and recovery analysis
* Circuit DNF risk trends
* Circuit winner-diversity analysis

## Key findings

* Hamilton dominated the late-2010s era through 2021.
* Verstappen emerged as the strongest recent performer after 2021.
* Williams experienced the longest historical drawdown.
* McLaren showed meaningful recovery despite remaining below its historical peak.
* Marina Bay, Zolder, and Mosport exhibited the highest recent winner diversity.
